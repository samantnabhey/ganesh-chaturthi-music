# Roadmap

## Phase 1: MVP ✅ (Done)
- [x] Custom YouTube Music player UI
- [x] Play/pause/next/prev controls
- [x] Seek bar + duration display
- [x] Festive Ganesh Chaturthi theme
- [x] Live listener counter (simulated)
- [x] Support/donation button
- [x] Mobile responsive design

## Phase 2: Enhancements (Next)
- [ ] Add multiple festival themes (Diwali, Holi, Navratri)
- [ ] Real-time listener count (Firebase Realtime DB)
- [ ] Ability to swap playlists without code changes (config.json)
- [ ] Analytics dashboard (view count, play stats)
- [ ] Share button (copy link + social)
- [ ] Dark/light mode toggle
- [ ] Playlist information panel (current track, artist, thumbnail)

## Phase 3: Advanced Features
- [ ] Admin dashboard (playlist management, stats)
- [ ] Multi-language support (Hindi, Marathi, English, etc.)
- [ ] Spotify integration (alternative to YouTube)
- [ ] Community submissions (crowd-sourced playlists)
- [ ] Email newsletter signup
- [ ] API for embedding player in other sites
- [ ] Native mobile app (React Native)

## Phase 4: Monetization & Growth
- [ ] Affiliate links (Buy Me a Coffee, UPI handlers)
- [ ] Merchandise store integration
- [ ] Sponsored playlists
- [ ] Premium features (ad-free, custom themes)
- [ ] Multi-festival platform (music for all Indian festivals)
